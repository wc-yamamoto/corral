# Corral の使い方

Corral は、ターミナルとコーディングエージェントのためのデスクトップアプリです。作業をスペースに分けて並べ、どのエージェントがあなたを待っているかを一覧し、ウィンドウを閉じてもターミナルを動かし続けます。

## インストール

いまはソースからビルドして使います。Node.js と npm が必要です。

```sh
npm install
npm run package
```

`out/Corral-darwin-arm64/Corral.app` ができます。`/Applications` に移して、ほかのアプリと同じように開いてください。

- Apple シリコンの Mac（M1 以降）で、macOS 13 以降が必要です。Intel の Mac では動きません。
- 開発中は `npm start` でリポジトリから直接起動できます。この場合、Dock やメニューバーの名前は「Electron」と表示されます。

### 他の人に渡す

Corral.app は Apple の開発者証明書ではなく、簡易署名（ad-hoc）しかしていません。そのため、AirDrop・Slack・ブラウザなどで受け取った Mac では、Gatekeeper が開くのを止めます（「開けません」や「壊れているため開けません」と表示されます）。

受け取った人は、`/Applications` に移したあと、どちらかで開けるようになります。

- **システム設定から**: 一度開こうとしてから、「システム設定 › プライバシーとセキュリティ」の下にある「このまま開く」を押す
- **ターミナルから**: `xattr -dr com.apple.quarantine /Applications/Corral.app` を実行する

渡す前に、信頼できる相手かどうかを確認してください。このアプリはターミナルを動かすので、改ざんされたものを開くと何でもできてしまいます。警告なしで開けるようにするには、Apple Developer Program（有料）の Developer ID で署名し、Apple の公証（notarization）を受ける必要があります。

## 画面の構成

```
┌──────────────┬─────────────────────────────────────┐
│ Spaces    +  │ タブ1 │ タブ2 │ +                     │
│ ● api      2 ├──────────────────┬──────────────────┤
│ ○ web      1 │                  │                  │
│              │   ペイン         │   ペイン         │
│ Agents       │  （ターミナル）  │  （ターミナル）  │
│ ● claude     │                  │                  │
│   Blocked    │                  │                  │
│ ● codex      │                  │                  │
│   Working    │                  │                  │
│ [Commands ⌘⇧P]│                  │                  │
└──────────────┴──────────────────┴──────────────────┘
```

- **左のサイドバー**: 上がスペースの一覧、下がすべてのスペースのエージェントの一覧です。`⌘B` で表示を切り替えます。
- **右側**: 上がタブ、その下がペインに分割されたターミナルです。

## スペース・タブ・ペイン

**スペース**は 1 つの作業のまとまりで、ふつうは 1 つのリポジトリに対応します。スペースの中に**タブ**があり、タブを**ペイン**に分割してターミナルを並べます。

| やりたいこと | 操作 |
| --- | --- |
| 新しいスペース | `⌘⇧N`、またはサイドバーの「+」 |
| スペースを切り替える | サイドバーでクリック、または `⌘⌃[` `⌘⌃]` |
| 新しいタブ | `⌘T`、またはタブバーの「+」 |
| タブを切り替える | クリック、`⌘⇧[` `⌘⇧]`、`⌘1`〜`⌘8`、`⌘9`（最後のタブ） |
| タブを並べ替える | ドラッグ |
| タブを閉じる | `⌘⇧W`、「×」、または中クリック |
| 右に分割 / 下に分割 | `⌘D` / `⌘⇧D` |
| ペインを移動 | `⌘⌥` + 矢印キー、またはクリック |
| ペインを一時的に最大化 | `⌘⇧↩`（もう一度押すと戻る） |
| ペインの大きさを変える | ペインの境界をドラッグ |
| ペインを閉じる | `⌘W` |
| 画面をクリア | `⌘K` |
| 文字の大きさ | `⌘=` `⌘-`、`⌘0` で元に戻す |
| 新しいウィンドウ | `⌘N` |

### 名前

- 名前のないスペースには、最初のターミナルのフォルダ名が表示されます。
- 名前のないタブには、フォーカス中のターミナルで動いているプログラム名かフォルダ名が表示されます。
- スペースやタブをダブルクリックすると名前を付けられます。名前を空にすると、フォルダ名の表示に戻ります。

新しいタブやペインは、フォーカス中のターミナルと同じフォルダで開きます。

## エージェント

Claude Code、Codex、Gemini CLI、aider、opencode などのコーディングエージェントを、ターミナルで動いているプログラムから自動で見つけます。見つけたエージェントは、サイドバーの「Agents」に全スペース分まとめて表示されます。

### 状態

| 状態 | 意味 |
| --- | --- |
| **Working** | 作業中 |
| **Blocked** | あなたの入力や承認を待っている |
| **Done** | あなたが見ていない間に作業が終わった |
| **Idle** | 待機中、または終わったのをあなたが確認済み |

一覧では、あなたの対応が必要なもの（Blocked、Done）が上に並びます。

- 見ていないエージェントが Blocked や Done になると、macOS の通知が出ます。通知をクリックするとそのエージェントを表示します。
- 対応が必要なエージェントの数が Dock のバッジに出ます。
- `⌘⇧A` で、次に対応が必要なエージェントへ移動します。
- サイドバーのエージェントをクリックすると、そのターミナルを表示します。

### 状態をもっと正確にする

状態は、画面に出ている文字（`esc to interrupt`、`Do you want to proceed?` など）やタイトルのスピナーから推測しています。推測ではなく正確な状態がほしい場合は、エージェントから報告させます。

Corral のターミナルでは `corral` コマンドが使えます。

```sh
corral report working|blocked|done|idle [--kind 名前]
corral report clear     # 報告をやめて推測に戻す
```

Claude Code なら、`~/.claude/settings.json` にフックを追加すると自動で報告します。

```json
{
  "hooks": {
    "UserPromptSubmit": [{ "hooks": [{ "type": "command", "command": "[ -n \"$CORRAL_TERMINAL_ID\" ] && corral report working --kind claude || true" }] }],
    "Notification": [{ "hooks": [{ "type": "command", "command": "[ -n \"$CORRAL_TERMINAL_ID\" ] && corral report blocked --kind claude || true" }] }],
    "Stop": [{ "hooks": [{ "type": "command", "command": "[ -n \"$CORRAL_TERMINAL_ID\" ] && corral report done --kind claude || true" }] }]
  }
}
```

このフックは Corral の外では何もしないので、ほかのターミナルで Claude Code を使っても影響はありません。

## 別のセッションにプロンプトを渡す

あるターミナルのエージェントから、別のターミナルのエージェントに仕事を頼めます。相手の ID（`t3` など）は `corral ls` で調べます。

```sh
corral ls                                   # ターミナルの ID を調べる
corral send t3 "src/x.ts をレビューして"    # プロンプトを送る
corral send --wait t3 "修正をもう一度確認して"  # 送って、作業が終わるまで待つ
corral read t3 --lines 100                  # 相手の画面と履歴をテキストで読む
corral wait t3                              # 作業が終わるまで待つ
```

### send

- 文字をペーストとして入力し、Enter を押します。複数行のプロンプトも、途中で送信されずに 1 つのメッセージとして届きます。
- `--no-enter` を付けると、入力するだけで送信しません。
- 本文を省くと、標準入力から読みます。例: `cat task.md | corral send t3`
- 自分自身のターミナルには送れません。

### wait

エージェントが Working でなくなる（Done、Blocked、Idle のどれかになる）まで待ちます。

| 終了コード | 意味 |
| --- | --- |
| 0 | 作業が止まった。表示された状態を確認する |
| 1 | ターミナルがなくなった、またはエージェントが動いていない |
| 2 | タイムアウト（`--timeout 秒`、既定 600 秒）。まだ作業中 |
| 3 | `send --wait` で送ったのに、作業が始まらなかった。`corral read` で画面を確認してから送り直す |

### うまく使うコツ

- 長い答えは、ファイルに書いてもらってそのパスを返してもらうと確実です。画面から読むより取りこぼしがありません。
- 終わったら知らせてほしいときは、プロンプトで頼みます。例: 「終わったら `corral send t1 "結果"` で知らせて」
- 起動した直後のエージェントに送ると、取りこぼすことがあります。`corral agents` に表示されてから送ってください。
- 作業が終わってから `wait` が返るまで、1〜2 秒かかります。

## コマンドパレットとキー設定

`⌘⇧P` でコマンドパレットを開くと、すべての操作を名前で探せます。スペースやタブの名前でも探せるので、移動にも使えます。

### キーを変える

`~/.corral/keys.json` でキーの割り当てを変えます。`⌘,` か、パレットの「Open keys.json」で開けます。

```jsonc
{
  "bindings": {
    "cmd+shift+t": "tab.new",
    "cmd+k": null            // 初期の割り当てを外す
  }
}
```

- 修飾キーは `cmd`、`ctrl`、`alt`、`shift` です。
- ファイルを保存すると、すぐに反映されます。
- 書き間違えた場合は、直前の正しい設定のまま、エラーが画面に表示されます。

### コマンド ID

| ID | 内容 |
| --- | --- |
| `palette.open` | コマンドパレット |
| `space.new` / `space.rename` / `space.close` | スペースを作る / 名前を変える / 閉じる |
| `space.next` / `space.prev` | 次 / 前のスペース |
| `tab.new` / `tab.rename` / `tab.close` | タブを作る / 名前を変える / 閉じる |
| `tab.next` / `tab.prev` | 次 / 前のタブ |
| `tab.goto_1` 〜 `tab.goto_8` / `tab.goto_last` | 指定した番号のタブ / 最後のタブ |
| `pane.split_right` / `pane.split_down` | 右 / 下に分割 |
| `pane.close` / `pane.zoom` | ペインを閉じる / 最大化 |
| `pane.focus_left` / `_right` / `_up` / `_down` | ペインを移動 |
| `agents.next_attention` | 次に対応が必要なエージェント |
| `sidebar.toggle` | サイドバーの表示 |
| `terminal.clear` | 画面をクリア |
| `font.bigger` / `font.smaller` / `font.reset` | 文字の大きさ |
| `window.new` | 新しいウィンドウ |
| `keys.open` | keys.json を開く |
| `core.restart` | コアを再起動（動いているプログラムは終了、レイアウトは残る） |

Linux と Windows の初期設定は、`Ctrl+Shift`、`Ctrl+Alt`、`Alt+1`〜`Alt+9` を使います。`Ctrl` だけのキーはシェルに渡ります。すべての初期設定は `src/shared/keys.ts` にあります。

## ウィンドウを閉じても動き続ける仕組み

ターミナルを動かしているのはウィンドウではなく、裏で動く **コア** というプロセスです。ウィンドウはコアにつないで画面を表示しているだけです。

- ウィンドウを閉じても、アプリを終了しても、ターミナルは動き続けます。もう一度開くと、画面がそのまま戻ります（スクロールバックは 5,000 行まで）。
- ペインやタブを閉じると、その中のターミナルは終了します。
- Mac の再起動やコアの停止のあとは、レイアウトはそのままで、各ペインが最後のフォルダで新しいシェルを開きます。前に動いていたプログラムは戻りません。

### データの保存場所

`~/.corral` に保存されます。このフォルダはあなたのユーザーしか読み書きできません。

| ファイル | 内容 |
| --- | --- |
| `state.json` | スペース・タブ・ペインのレイアウト |
| `keys.json` | キー設定 |
| `core.log` | コアのログ |
| `core.sock` | ウィンドウや `corral` コマンドがコアにつなぐためのソケット |

環境変数 `CORRAL_HOME` で保存先を変えられます。

### アプリを更新したとき

新しい Corral.app を開いても、すでに動いているコアは古いままです。新しいコアに切り替えるには、パレットの「Restart core」を実行してください（`corral stop` でも止められます）。動いているターミナルはすべて終了し、レイアウトは残ります。

## corral コマンド一覧

Corral のターミナルの中では、`corral` コマンドが使えます。外から使う場合は、リポジトリの `bin/corral` を実行してください。

| コマンド | 内容 |
| --- | --- |
| `corral ls` | スペース・タブ・ターミナルの一覧 |
| `corral agents` | エージェントと状態の一覧 |
| `corral send <t> <文>` | ターミナル t にプロンプトを送る（`--no-enter`、`--wait`、`--timeout`） |
| `corral read <t> [--lines N]` | ターミナル t の最後の N 行を表示（既定 50 行） |
| `corral wait <t> [--timeout 秒]` | ターミナル t のエージェントの作業が終わるまで待つ |
| `corral report <状態> [--kind 名前]` | このターミナルのエージェントの状態を報告する |
| `corral stop` | コアを止める（全ターミナル終了、レイアウトは残る） |

## 困ったとき

**Dock のアイコンや名前が古いまま**
macOS のアイコンのキャッシュが残っています。Dock から一度外すか、ログインし直してください。

**「corral core is not running」と出る**
コアが動いていません。Corral のウィンドウを開くと、コアが自動で起動します。

**エージェントの状態が実際と違う**
状態は画面から推測しているので、ずれることがあります。[フックで報告させる](#状態をもっと正確にする)と正確になります。

**`corral send` で送ったプロンプトが送信されず、改行になる**
エージェントがペーストを受け取り終える前に Enter が届いています。`src/daemon/index.ts` の `SUBMIT_DELAY_MS`（いまは 200ms）を延ばしてください。

**キー設定が効かない**
画面にエラーが出ていないか確認してください。書き間違いがあると、直前の正しい設定のまま動きます。

**原因がわからない**
`~/.corral/core.log` にコアのログがあります。
